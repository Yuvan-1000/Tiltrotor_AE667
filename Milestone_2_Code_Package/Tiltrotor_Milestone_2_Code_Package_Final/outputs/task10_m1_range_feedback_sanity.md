# M1 grading-feedback regression: cruise-range shape

For steady level airplane-mode flight at h=500 m and gross mass 3000 kg, the required-lift drag calculation produces an internal range peak at 48.0 m/s (776.3 km). At the highest tested speed (140.0 m/s) the range is 163.7 km, so the curve decreases at the high-speed end. This directly addresses the M1 grading feedback; it is retained as a regression/sanity check in M2.
