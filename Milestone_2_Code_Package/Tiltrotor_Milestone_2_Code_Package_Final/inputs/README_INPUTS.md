# Input examples

`aircraft_config.json` is generated from the single configuration source and mirrors the values used by all task drivers.

`control_sweep_conditions.json` documents the two required Task 5 demonstration operating points.

`trim_cases.csv` is the required 3×3 Task 7 matrix: nacelle angles 90°, 45°, 0° and airspeeds 20, 30, 40 m/s at 500 m, 3000 kg, ISA, zero wind and zero climb rate.

`example_transition_outbound.json` and `example_transition_inbound.json` are complete user-editable Mission Planner v2 examples. Each contains segment duration, airspeed, altitude, nacelle angle, RPM and control schedules.
